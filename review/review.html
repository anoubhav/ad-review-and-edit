About this page

The questions, options and decision rules sit in the RUBRIC constant at the top of this file's script. The release's docs/REVIEW_PAGE.md explains the ad package format and the downloads.

1. Reviewer code

A pseudonym such as R1. Do not type a name. The release uses R1 to R5 for the round's reviewers.

Use R followed by one to three digits, such as R6.

2. Judge findings

Judge findings

The code and this choice are fixed once you have answered anything. Clear all reviews below to change them.

3. Ads to review

Choose one or more package files (.json), their videos and any reference photos together. Files are matched by name. A findings.jsonl file adds its findings to the packages with the same ad_id.
